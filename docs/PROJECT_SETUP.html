Laravel Project Setup Instructions

Rajabharana Jewellery Management System · Environment & Installation

1. Software Prerequisites

SoftwareVersionPurpose
PHP8.2+Laravel runtime
Composer2.xPHP dependencies
Node.js / NPM18+ / 9+Frontend build (Vite, Tailwind)
MySQL8.xDatabase
php -v
composer --version
node -v
npm -v

2. Project Creation

1 Create Laravel project
composer create-project laravel/laravel jewellery-system
cd jewellery-system
2 Install Laravel Breeze (authentication)
composer require laravel/breeze --dev
php artisan breeze:install blade
3 Install dependencies
composer install
npm install

3. Environment Configuration (.env)

copy .env.example .env
php artisan key:generate

Application settings

APP_NAME="Rajabharana Jewellery"
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

MySQL database

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=rajabharana_jewellery
DB_USERNAME=root
DB_PASSWORD=

SESSION_DRIVER=database
QUEUE_CONNECTION=database

Create database first:

CREATE DATABASE rajabharana_jewellery
  CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

4. Database Setup

php artisan migrate
php artisan db:seed

5. Storage & Frontend Build

php artisan storage:link
npm run build

Development with hot reload: npm run dev

vite.config.js

export default defineConfig({
    plugins: [
        laravel({
            input: ['resources/css/app.css', 'resources/js/app.js'],
            refresh: true,
        }),
    ],
});

6. Run Application

php artisan serve

Open: http://127.0.0.1:8000

Or use combined dev mode: composer run dev

One-shot first setup: composer run setup

7. Setup Flow

flowchart TD A[Install Prerequisites] --> B[composer install] B --> C[Configure .env] C --> D[key:generate] D --> E[Create MySQL DB] E --> F[migrate] F --> G[db:seed] G --> H[storage:link] H --> I[npm install + build] I --> J[php artisan serve] J --> K[localhost:8000]

9. Report Paragraph

The Rajabharana Jewellery Management System was developed on Laravel 12 with PHP 8.2, using Composer for backend dependencies and NPM for frontend tooling. The project was initialized with the Laravel installer and Laravel Breeze for authentication. Environment variables were configured in the .env file for MySQL and database-backed sessions. Schema was created using migrations (php artisan migrate) and sample data inserted using seeders (php artisan db:seed). Frontend assets were compiled with Vite and Tailwind CSS. The application was served locally using php artisan serve at http://127.0.0.1:8000.
