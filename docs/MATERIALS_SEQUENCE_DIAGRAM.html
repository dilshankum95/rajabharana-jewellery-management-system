Figure 2 — Adjust Raw Material Stock (UC-M05)

Manual stock increase or decrease. Creates a stock_movements audit record with reason material_received or workshop_usage.

sequenceDiagram autonumber actor Manager as Inventory Manager participant UI as Material Edit UI participant RC as RawMaterialController participant Req as AdjustRawMaterialStockRequest participant IS as InventoryService participant RM as RawMaterial participant SM as StockMovement participant DB as Database Manager->>UI: Enter quantity delta and note UI->>RC: POST /admin/raw-materials/id/adjust-stock RC->>Req: validate and authorize Req-->>RC: quantity_delta, note RC->>IS: adjustRawMaterialStock(material, delta, reason, user) IS->>DB: BEGIN TRANSACTION IS->>RM: lockForUpdate() IS->>IS: calculate quantity_after alt Insufficient stock IS-->>RC: InvalidArgumentException RC-->>UI: redirect with error UI-->>Manager: Insufficient stock message else Stock OK IS->>RM: update stock_quantity IS->>SM: recordMovement() SM->>DB: INSERT stock_movements IS->>DB: COMMIT RC-->>UI: redirect with success UI-->>Manager: Stock adjusted successfully end

Figure 3 — Link Materials to Catalog Item (UC-M06 + UC-M07)

Manager sets catalog stock quantity and Bill of Materials (quantity_required per material per 1 catalog unit).

sequenceDiagram autonumber actor Manager as Inventory Manager participant UI as Catalog Edit UI participant CC as CatalogDesignController participant Req as UpdateCatalogDesignRequest participant CD as CatalogDesign participant IS as InventoryService participant DB as Database Manager->>UI: Edit catalog stock and linked materials UI->>CC: PATCH /admin/catalog/id CC->>Req: validate fields and materials array Req->>Req: filter empty material rows Req-->>CC: validated data CC->>CD: update catalog fields including stock_quantity CD->>DB: UPDATE catalog_designs CC->>IS: syncCatalogAvailability(design) Note over IS: stock=0 sets OutOfStock CC->>IS: syncCatalogMaterials(design, materials) IS->>DB: SYNC catalog_design_raw_material CC-->>UI: redirect with success UI-->>Manager: Catalog item updated successfully

Figure 4 — Customer Places Catalog Order (UC-M11)

Stock is validated at order time but not deducted. Order is saved as Pending.

sequenceDiagram autonumber actor Customer participant UI as Order Form participant OC as OrderController participant Req as StoreOrderRequest participant CD as CatalogDesign participant DB as Database Customer->>UI: Select catalog item and quantity UI->>OC: POST /orders OC->>Req: validate order data Req->>CD: load catalogDesign and rawMaterials Req->>Req: check catalog stock_quantity >= quantity loop Each linked raw material Req->>Req: required = quantity_required x order_qty Req->>Req: check material stock >= required end alt Stock insufficient Req-->>OC: validation errors OC-->>UI: redirect back with errors UI-->>Customer: Only X units or insufficient workshop stock else Stock sufficient Req-->>OC: validated OC->>DB: INSERT orders status Pending Note over DB: No stock deducted yet OC-->>UI: redirect success UI-->>Customer: Order placed awaiting acceptance end

Figure 5 — Accept Catalog Order — Auto Deduct Stock (UC-M09)

Admin accepts order. InventoryService deducts catalog stock and all linked raw materials. Audit logged in stock_movements.

sequenceDiagram autonumber actor Admin participant UI as Order Detail UI participant OC as OrderController participant IS as InventoryService participant Order as Order participant CD as CatalogDesign participant RM as RawMaterial participant SM as StockMovement participant DB as Database Admin->>UI: Change status Pending to Accepted UI->>OC: PATCH /admin/orders/id OC->>IS: deductForAcceptedOrder(order, admin) IS->>DB: BEGIN TRANSACTION IS->>Order: load catalogDesign.rawMaterials IS->>IS: assertCatalogStockAvailable() IS->>IS: assertRawMaterialStockAvailable() alt Insufficient stock at accept time IS-->>OC: InvalidArgumentException OC-->>UI: redirect with error UI-->>Admin: Cannot accept order error else Stock OK opt Catalog deduction not yet recorded IS->>IS: adjustCatalogStock design minus orderQty IS->>SM: INSERT stock_movements CatalogDesign IS->>IS: syncCatalogAvailability() end loop Each linked raw material opt Material deduction not yet recorded IS->>IS: adjustRawMaterialStock minus required IS->>SM: INSERT stock_movements RawMaterial end end IS->>DB: COMMIT OC->>Order: update status Accepted OC->>DB: INSERT production_log OC-->>UI: Order updated successfully end

Figure 6 — Reject Accepted Order — Restore Stock (UC-M10)

If an accepted order is rejected, catalog stock and linked materials are restored with audit records.

sequenceDiagram autonumber actor Admin participant UI as Order Detail UI participant OC as OrderController participant IS as InventoryService participant Order as Order participant SM as StockMovement participant DB as Database Admin->>UI: Change status Accepted to Rejected UI->>OC: PATCH /admin/orders/id OC->>IS: restoreForRejectedOrder(order, admin) IS->>DB: BEGIN TRANSACTION IS->>Order: load catalogDesign.rawMaterials opt Catalog deduction exists IS->>IS: adjustCatalogStock design plus orderQty IS->>SM: INSERT stock_movements CatalogDesign IS->>IS: syncCatalogAvailability() end loop Each linked raw material opt Material deduction exists IS->>IS: adjustRawMaterialStock plus required IS->>SM: INSERT stock_movements RawMaterial end end IS->>DB: COMMIT OC->>Order: update status Rejected OC-->>UI: Stock restored UI-->>Admin: Order rejected stock restored

Figure 7 — Generate Inventory Report (UC-M12)

Inventory Manager views category-wise catalog stock KPIs and raw materials summary including low-stock count.
